# plant-finder
A simple plant finder application that narrows down a list of plants based on needs.

In progress – some cleaning up and additionally database fields, plus further search fields should be added as well as more plants. This project is designed to narrow down a database of plants based on various factors such as soil type and soil pH. In the future, fields should be added for the types of borders the plants go in as well which facing direction. The project uses SQLite, as well as Streamlit for the interface. I figured the project would be good to test database skills, as well as learn something new.

Tutorials found online of how to use SQLite, as well as the official Streamlit documentation helped with this project.
